# AI System 6 Product Notes

AI System 6 is a local-first AI writing environment for source-based writing.
It protects a writer's own language, sources, judgment, feeling, and handoff
intent from collapsing into generic model language.

AI can help read, organize, draft, rewrite, and review, but it must not become the writer's mouthpiece. The product should preserve rough human input,
personal detail, hesitation, and diverse flaws when they carry voice or
judgment.

The core route is:

```text
Project Hard Disk -> File Floppy -> Question Sheet -> Outline -> Section Drafts -> Manuscript -> Review Desk -> Project CD
```

Question Sheet must welcome messy human input before prose: real recipient, raw
questions, personal observations, objections, usage details, pressure points,
and handoff friction.

Review Desk must check for AI-mouthpiece drift as well as factual and
structural risk.

For setup and commands, see `README.md`.
