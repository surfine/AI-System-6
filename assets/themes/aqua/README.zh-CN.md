# Aqua Theme Lab 图稿

英文版为准。本文档仅供人类参考，不被任何脚本读取。

这些小型 SVG painter 是 AI System 6 根据 Mac OS X 10.2 截图中可验证的
几何与材质关系重新绘制的原创图稿，并非从 Quaqua 或 Apple 系统资源复制。
Quaqua 所附图稿受 Apple 版权保护，只能作为本地取证材料。

参考角色：

- `startup-disk.svg`：Jaguar 时代的银色磁盘轮廓
- `folder.svg`：早期 Aqua 蓝色文件夹轮廓
- `document.svg`：带折角的白色 Aqua 文档
- `finder-app.svg`：项目原创的双色 Finder 应用替代图稿
- `trash.svg`：半透明蓝色废纸篓替代图稿
- `menu-system-mark-16.svg`：项目原创的蓝色 AI System 6 菜单标志，刻意不使用 Apple 标志
- `menu-speaker-16.svg`：项目原创的 16px 菜单状态扬声器
- `toolbar-back.svg` 与 `toolbar-forward.svg`：24px 珠光导航控件
- `toolbar-computer.svg`、`toolbar-home.svg`、`toolbar-favorites.svg` 与
  `toolbar-applications.svg`：项目原创的 28px Finder toolbar 角色图标
- `view-icon-12.svg`、`view-list-12.svg` 与 `view-columns-12.svg`：项目原创的紧凑视图模式图标
- `browser-volume-16.svg`、`browser-folder-16.svg` 与
  `browser-document-16.svg`：项目原创的 16px NSBrowser 行图标
- `sheet-warning-64.svg`：attached sheet fixture 的原创警告符号；刻意不包含 Finder 或 Apple 图稿

几何与状态参考：

- GUIdebook 收录的原生 1× Mac OS X 10.2 Finder、Open panel、menu bar 与 Address Book 截图
- Apple 2002 年 6 月版 *Aqua Human Interface Guidelines*：20px push／pop-up、22px text field、18px choice 与 alert 排版
- Quaqua 9.1 Jaguar file chooser／browser 实现：可重复核对 column 与 scrollbar 状态关系

此目录中的 SVG 路径与渐变均为项目原创。不得用抽取的 Aqua resource、
Quaqua PNG、Apple 应用图标或截图裁片替换。Quaqua 图像与原系统截图只保留为
本地证据，不进入产品资产。
