# Liquid Glass icon family

This directory contains the original Liquid Glass appearance for AI System 6's 54 semantic objects. The family is generated by `scripts/build-era-icons.mjs` at 128, 64, 32, and 16 pixels. Runtime icons use the 32-pixel SVGs; Theme Lab also shows the separately simplified 16-pixel hint.

The construction follows four rules from Apple's current guidance: begin with a simple, memorable metaphor; keep the layer count controlled; let specular light, translucency, refraction cues, and shadows belong to the artwork layers; and inspect every presentation size. App-like objects can use a bounded canvas, but folders, documents, disks, tools, and media retain their own silhouettes. No shared CSS glass tile is placed behind the family.

Reference ledger and acceptance criteria live in `../era-icon-reference.json`. The runtime mapping is `liquid-glass-icon-manifest.json`, and the full per-size ledger is `liquid-glass-icon-family.json`.

Official design evidence:

- https://developer.apple.com/icon-composer/
- https://developer.apple.com/design/human-interface-guidelines/app-icons/
- https://developer.apple.com/videos/play/wwdc2025/361/
- https://developer.apple.com/design/human-interface-guidelines/materials

All shipped artwork is original SVG construction. Apple screenshots and design resources are reference-only and are not embedded, cropped, traced, or redistributed here.
