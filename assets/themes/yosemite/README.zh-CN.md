# Yosemite 图标家族

本目录是面向 OS X 10.10 Yosemite 的完整 54 项 AI System 6 图标家族。每个 ID 都有 128×128、64×64、32×32 与 16×16 作品。

Yosemite 绘制器与 Liquid Glass 完全独立，使用 Retina 时代的扁平物件轮廓、浅钢蓝发丝线、浅层色面、极少明暗和紧凑的视觉中心。它不是统一描边 glyph 包，不把所有应用塞进圆角方形，也不继承玻璃胶囊、折射或 Liquid Glass 几何。

`yosemite-icon-manifest.json` 映射运行时 32px 文件，`yosemite-icon-family.json` 记录全部尺寸与隐喻，确定性源文件是 `scripts/build-era-icons.mjs`。

证据记录在 `../era-icon-reference.json`。历史 Apple 与 GTK 资产只作研究；不会嵌入、裁切、描摹或随产品分发。
