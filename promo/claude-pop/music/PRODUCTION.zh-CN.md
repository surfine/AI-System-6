# Pen Pal：制作笔记

`build/song.wav` 是如何由 `music/score.json` 做出来的，每一种声音是什么，以及如何重建它。
一切都是代码：人声用 Piper TTS + Praat PSOLA，桌面鼓组和
软盘驱动器用 numpy/scipy 合成，钢琴、风琴、铜管、弦乐和萨克斯用 FluidSynth（FluidR3 GM）。没有采样。

## 重建

```bash
python3 -I music/song.py && python3 -I music/validate_score.py && python3 -I music/export_timing.py   # the score (never hand-edit score.json)
python3 -I music/build_song.py              # render + measure (about 10 min; 2 min of it is Whisper)
python3 -I music/build_song.py --no-qa      # render only
python3 -I music/build_song.py --prune-cache   # also delete cached words/parts this build no longer uses
```

输出：`build/song.wav`（48 kHz、24-bit、立体声）、`build/stems/{lead,chant,choir,spoken,drums,bass,keys,other}.wav`
和 `build/song-qa.json`（下文每一项测量值）。

**确定性。** Piper 以 `noise_scale = noise_w_scale = 0` 运行（它的随机采样器无法设种子，所以
被关掉了）；其他每一个随机选择（人性化、颗粒、噪声、团伙散布）都来自一个带种子的
生成器（`dsp.rng`，一个名字的 FNV 哈希，绝不是 Python 带盐的 `hash()`）；Praat 的叠加合成（它
随机放置清音的伪周期）按词设种子；FluidSynth 离线渲染。连续两次
构建产生逐比特相同的 `song.wav` 和各分轨（用 md5 检查）。
**缓存**在 `.cache/`（被 git 忽略）：`tts/` 逐词的原始 Piper，`sing/` 以每一个输入（文本、音符、上下文、风格、`voice.ENGINE_VERSION`）为键的完成 PSOLA 词，
`fluid/` 以音符为键的每个 GM 声部，
`phonemes.json`。改动演唱引擎后删除 `.cache/sing`（或提升 `ENGINE_VERSION`）；
1,303 个唱出的词的首次完整渲染在 4 核上约需 80 秒，用缓存约 20 秒。

## 1. 人声引擎（`voice.py`）

每个唱出的词：

1. **Piper** 从 IPA 说出这个词（`phonemes_for`，带演唱覆盖：唱出的"the"是 *thee*，la 是 *lah*，
   in-SERT / ex-PORT 的重音，每一个唱出的词都强制一个主重音）。长音要求 Piper 说得
   更慢（音符 < 0.4 / 0.7 / 1.1 / 更长秒数时 `length_scale` 分别为 1.0 / 1.35 / 1.8 / 2.3），好让元音有
   更多自身可以延续。以爆破音开头的词，在一个载体"the"之后说出、并在
   闭塞处切断：从静音开始时 Piper 的 /p/ 是带气的（听成"h"：*pen* 出来的是 *hand*），在元音之后
   它得到一个真正的闭塞和爆发。
2. **修整**，峰值归一化；可选的**共振峰移位**（以 1/k 重采样，PSOLA 之后恢复音高和时间）。
3. **分析**（5 ms 帧）：用 Praat 自相关法分析音高并判断清浊音，一条 150-4000 Hz 的强度曲线。
   每个音节一个**元音核心**：最响的浊音峰彼此由一个 >= 1.5 dB 的下凹分开，每一个都扩到
   -7 dB；多音符词（`syl`）在这些下凹处切分，即按浊音段切，而不是均匀切。
4. **时间变形**（Praat DurationTier，分段常数）：起音辅音被放在音符*之前*
   （受每个音素的预算限制：p 35 ms、s 85 ms、……），好让元音落在拍上；音节之间的
   辅音正好坐在下一个音符之前；元音在一个 30 ms 的**保持
   窗口**周围延续（双元音里靠前，这样它像歌手那样晚些滑过去；/ɛ/ 在鼻音前靠后；其余情况
   居中），而核心其余部分连同它的共振峰过渡以自然速度运行；结尾的
   n / m / l（也在 d、t、z 之前：*land*、*hold*）占音符的 40%；一个阻音尾音在一个
   阻音起音之前，会在下一个词开始前结束（没有"page-stay"拖尾）。
5. **音高**（PitchTier，在输出时间里设计，然后通过变形映射回来）：从前一个音符
   滑入（70 ms smoothstep），连唱词内部的滑音（60 ms），音符 >= 0.45 s 上 40 音分的
   上滑，颤音 5.4 Hz +/-24 音分在 0.3 秒后到达、带 0.25 秒的渐入，双正弦漂移 +/-5 音分，
   乐句结尾 35 音分的下落。
6. **叠加合成重合成**，22.05 -> 48 kHz（`resample_poly`），辅音强调（起音、音节间
   和阻音尾音辅音 +4 dB，"the" +6 dB），连唱里柔和的（非声门）元音起音
   （元音之后的声门塞音会被听成 *b*），4 / 12 ms 边缘淡化。词在时间线上叠加合成，
   所以词之间的交叉淡化就是词自己的辅音重叠。
7. **咬字**（`sing-v21`，在 QA 第一轮发现 *pen* 被听成"hand" / "N"、*page* 被听成"H"、*check* 被听成
   "share"之后）：
   - **原始起音。** 一个清音起音（p / t / k / ch 的爆发和送气，一个 f、s、sh、th 或 h）
     不从 PSOLA 取，因为它随机的清音伪周期会把一个爆发抹成气声；它从
     Piper 源以自然速度拼接过来，放置得让浊音正好从变形放置它的地方开始（那个
     辅音坐在音符之前，像歌手的）。一个塞音保留它头 30 ms（爆发）且总共至多
     70 ms（一段长送气的中间被丢掉）；一个擦音保留它最后 120 ms。塞音和
     *h* 在那一段上多得 +5 dB（`burst_boost`）。
   - **闭塞。** 一个塞音只有在一段静音之后才被听到：当下一个词以 p / t / k / b / d / g /
     ch / j 开头时，它之前的词淡出（30 ms 释放），于是它在下一个音符之前静音 105 ms（清音）
     或 70 ms（浊音），即在爆发前 35 ms（"the | pen"、"can | check"、"You | do"）；绝不在
     它自己最后一个音符的 45% 之前。
   - 功能词比内容词低 1.5 dB（本来 2.5），而"your"、"who"、"where"、"I"不再被
     当作功能词：它们承载论点。
8. **咬字**（`sing-v22`，在 QA 第二轮发现钩子里那个低的 *pen* 在领唱分轨单独听时被听成"pan"、以及
   前副歌那些动词被听成"I can't buy, I can't buy"之后）：
   - **清楚的尾音。** 一个塞音或擦音尾音（*fetch*、*desk*、*it*、*rough*）在自己的音符内结束，即使
     下一个词以元音开头也是如此；以前，元音到元音的连唱规则会让它跑到下一个词
     之下（"fetch I" -> "vie"，"One desk. And" -> "One, two, and"）。
   - **那个低的 pen。** 写在 E4 或以下的"pen"（副歌 *A* 句"I'll never hold the pen."，D4 / E4，以及
     间奏的 C4）用半闭的 /e/ 唱：PSOLA 在 /n/ 之前的 /ɛ/ 在那么低的地方会张成 /æ/。（/ɪ/ 也
     修好了分轨，但在乐队之下读成"pin" / "deep in"。）D5 钩子和 F#4 / G#4 那句呼唤保留 /ɛ/
     （`vocals.low_pen`）。
   - **非重读的 *can*。** "can"是 /kən/：一个重读的 /kæn/ 被下一个词的闭塞切断会被听成"can't"。
   - **念唱里的 *the*** 说成 /ðə/，绝不是唱出的 *thee*（"Clip the proof"曾是"Clippy proof"，"Ask the
     question"是"Assy question"）。
   - **擦音起音**在 15 ms 内渐强（从静音开始，一个硬边的 f 会被听成 p），在念唱里，一个以 f / s / sh / th 开头的内容词
     之前的那个词会在它的音符前 70 ms 停止浊音（否则那个 f 会
     被浊化："can | file" -> "can vile"）。
   - 过桥的"Oh-five." / "Oh-nine."每个都作为两个词唱（"Oh" + "five."）：作为一个双音符词，Whisper
     只听到"Oh"。"Rough"（主歌 2）用一个长元音唱，并在"edge?"前 60 ms 结束。

用 Praat 对每个渲染出的词测量：领唱中位数 2.1 音分，la-la 1.4，切片 0.6；每个音符都在 25 音分以内。

| chops | boot 采样自己的 Piper"pen" / "pal"（长度尺度 1.35），由 PSOLA 重新定音高到 D5 / B4，正好从事件上开始，硬门控到写定的长度（8 ms 释放） | intro 里 8-bit，后副歌里干净；比领唱低 4 dB |

笑料：**FADE**（副歌"fade."）把这个词保持住这一拍的 30%，然后音高从 B4 滑到 G4；只有尾音
溶解：从这一拍的 55% 起比特深度从 16 掉到 5、电平下沉 12 dB（先听到的是"or I fay-"），乐队压低 6 dB 并抖动（7-bit TPDF）一拍，然后半拍真正的静音（43.0-43.25、
91.0-91.25、135.0-135.25 秒：乐队在半拍前 10 ms 就没了，领唱的尾音进入半拍 40 ms，两者
都从大约 -45 dBFS 起；在"and"上的"I'm"之前从 +40 ms 到 6 ms 是数字零）。**smooth**（前副歌 2）：一条低通
在这个词上从 8 kHz 扫到 1.5 kHz。
**Keep it.**：+/-10 音分，起音晚 20 / 8 ms。**那支无声的笔**：见下文的静音窗口。**voice.**：
这个词唱到 150.75 秒，然后元音的两个周期（取自 *s* 被检测到之前 12 ms：即 4 kHz+ 频带
第一次与整体相差 12 dB 以内的那一刻）循环到 151.0 秒，然后是 *s*。（一个重复的、更早的
`_freeze`，从音符结尾循环并丢掉 *s*，曾把这个遮蔽了；它已经没了。）

## 3. 贝斯（`synth.floppy_voice`、`synth.sub808`）

每个驱动器都是一台**步进电机**：一列音符频率上的脉冲（分数放置）与
一个 12 ms 机械步进响应（180 Hz 闷响 + 820 Hz 塑料 + 2.3 / 4.6 kHz 金属振铃）卷积，
一个 50% 脉冲用于音高，每个音符前 28 ms 一次 10 步**寻道啁啾**，以及磁头每 80 步
翻转一次方向（一次电平下凹）。驱动 A（根音）声像 -0.9，驱动 B（八度 / 五度）+0.9，两者都高通（130 / 160 Hz），
好让低频保持单声道。它们下面是一个**干净的正弦低音**，在驱动 A 的基频上（驱动 B 的基频 -10 dB）。那个
**808**（副歌 + 过桥落下）：一个正弦带 120% 音高踢、在 18 ms 内衰减，tanh 驱动 1.6，
每记底鼓把它压低 12 dB 持续 90 ms。间奏的驱动器被渲染得很柔（主要是低音）。140 Hz 以下的一切
在贝斯总线上被求和成单声道。

## 4. 键盘及其余部分（`band.py`）

- **Floppy Organ**（乐句、花饰、主歌 2 低一个八度的风琴）：GM 17 打击风琴 + 一个 numpy 25%
  脉冲，每次起音带一个 6 ms 的下行音高骤降和一个 8 ms 的 2-3 kHz 步进器咔哒。沿
  `eras` 时间线按时代压碎：1988 年 8-bit 11 kHz -> 10-bit 22 kHz（1999）-> 12-bit 32 kHz（2002）-> 从 2011 年起干净。
  过桥伴奏：GM 16 拉杆风琴顿音按底鼓节奏。
- **Piano** GM 1 副歌里的反拍八分（配器抬升一个八度，所以在 PEN 下 Cmaj9 顶上是 D5），
  间奏里的 GM 0 毛毡钢琴（2.6 kHz 低通），尾声最后一句之下的 GM 1。
- **Strings** GM 48 在前副歌之下，CC11 在 13.5 拍里渐强，在 HAND 上停下。
- **Pads**：5 声部失谐 supersaw（副歌，2.6 kHz），过桥的扫频铺底（8 拍里 300 Hz -> 7 kHz），
  旋转上升音之下、在重启时戛然而止的 E7sus4 铺底。
- **启动和弦**（以及重启的 Dmaj9 和结束的 Amaj9 和弦）：一个 7 声部锯齿铺底，其低通在 4 拍里
  从 400 Hz -> 9 kHz 打开，低四个音上有一个 FM 钟，根音下有一个正弦；顶部的音只有铺底，
  绝不是一声"叮"。
- **铜管顿音**：GM 61 铜管组 + 一个 3 声部锯齿层带 60 ms 滤波器骤降（去重）。
- **Sax**：GM 66 次中音。**Writing Bell**：双算子 FM（比率 3.5，指数 3.2 在 180 ms 内衰减）+ 一个 2.76x
  分音和一个滴答。**Beeps**：方波，1/4 拍。**Blips**：被敲出的动词上 30 ms 1568 Hz 叮声。
- FluidSynth：`-R 0 -C 0 -r 48000 -O float`，每个声部渲染一次并缓存；它每个音色的起音延迟
  由校准音符测得并移除，所以 GM 音符在它们拍点 3 ms 内开始。

## 5. 混音（`mix.py`）

通道条（每条轨道先归一化到 -18 dB 有效值 RMS）：

- **Lead**：HP 95 Hz（24 dB/oct）-> 分频段去齿音（6.5 kHz，5:1，最多 9 dB）-> EQ（+1 dB 170 Hz，
  -3.5 dB 320 Hz 浑浊，-1 dB 1 kHz，+2.5 dB 3.6 kHz 临场感，+2.5 dB 9.5 kHz 高架）-> 压缩器 4:1（4 ms /
  80 ms）-> 平整器 2:1（20 ms / 250 ms）-> 激励器（饱和 3.5 kHz+ 频带，7.5 kHz 以上的新谐波：
  22 kHz TTS 没有的空气感）-> 温和的 tanh。只在副歌里，领唱和
  合唱团在 420 Hz -3 dB（Q 1）：它们的 D4-D5 基频曾是混音里 400 Hz 的一坨。
- **Chant**：如前，外加一个 4.5 kHz 的分频段去齿音，其阈值是念唱自己 4.5 kHz+ 电平的
  第 97 百分位（所以只有最热的辅音被处理），最多 3 dB。
- **Sends**：一块合成的**板式**（2.4 s，28 ms 预延迟，频率相关的衰减，去相关的 L/R），
  **在干领唱下被 4:1 压低**；一条**1/8 附点乒乓延迟**（375 ms，反馈 0.33，每次重复
  更暗），**在干领唱下被 6:1 压低**，好让回声只在空隙里绽放，每个乐句结尾 +8 dB **抛送**。按段落自动化：
  boot 里裸而湿（-8 dB 板式），念唱段落干，副歌里 -15 dB 板式，间奏和尾声更湿。
- **Sidechain**：一条底鼓触发的泵动（2 ms 预爬升，6 ms 保持，平方的 170 ms 释放），各段落深度：
  副歌里贝斯 6 dB / 后副歌 5 / 其他 3，铺底 9，钢琴 3.5，弦乐 4，风琴 2-3，合唱团 2-2.5，
  切片 3；808 有自己的 12 dB / 90 ms 下压。
- **鼓总线**：底鼓 / 军鼓 / 踩镲 / 拍手 / 镲 / 打击乐以固定的相对增益混合，2.5:1 胶水
  压缩器，22% 并行饱和；军鼓和拍手送板式（暗，副歌里 -16 dB）和一个
  0.5 秒房间。
- **校准**：每条总线都按它在乎的窗口设定一个响度目标（pyloudnorm）
  （副歌里领唱 -14 LUFS，领唱加倍 -22.5，主歌里念唱 -16.8，后副歌里合唱团 -18.5，团伙在"You do!"小节里比领唱高 3 LU，副歌里鼓 -16 和贝斯 -19，风琴
  在 intro 和主歌 2 里 -19.5，毛毡钢琴 -23，……）；测量值和增益在 `song-qa.json`
  -> `mix.calibration`。领唱和念唱在 QA 第一轮后升了 3 / 1.5 dB：床在它原来的地方时，
  Whisper 在完整混音里丢掉了钩子（见第 7 节）。
- **人声口袋**（`dsp.pocket`，一个动态 EQ）：鼓（3 dB）、键盘及其他（4.5 dB）在 300 Hz-5 kHz 里最多损失那么多，
  只要干领唱、念唱或口白在其响亮电平 6 dB 以内，就在它以下 18 dB 处淡出
  （4 ms 起音，120 ms 释放）：乐队为每个词让出空间，在空隙里又拿回去。
- **低频**：808 比第一轮低 7 dB（它曾在 33-37 Hz 演奏 C1 / D1，在大多数音箱之下）；底鼓
  在 35 Hz 高通（24 dB/oct）；贝斯总线在 220 Hz +2.5 dB（Q 0.8），键盘也一样
  （人声之下的身体，160-300 Hz 的洞），副歌里 63 Hz -1.5 dB（Q 1.2），后副歌里 -3 dB。
- **后副歌**：鼓和贝斯在能量求解前 -1.5 dB（求解器把乐队抬回来，所以
  弹跳变得明亮，不是更安静），按键踩镲 +4 dB，鼓总线 63 Hz -2.5 dB、5 kHz 以上 +3 dB，合唱团、切片和
  风琴上 5 kHz +3.5 dB 高架，拍手上 6 kHz +3 dB。
- **间奏**：第 1-3 小节贝斯总线在 110 Hz 低通（24 dB/oct）并降 9 dB（G 踏板和那些
  柔和的驱动器曾是这一段最响的东西）；第 4 小节（E2 低音）在能量求解后 -4 dB；旋转上升音 -4 dB；响指
  和拍手在第 2-3 小节 -2 dB；毛毡钢琴低 2 dB。
- **其他自动化**：前副歌上升音在 HAND 停止前最后两拍 -3 dB；过桥的
  风琴伴奏和蜂鸣在"Oh-five. Oh-nine."之下 -2.5 dB，最后两句过桥行之下风琴也一样；
  "other"总线（顿音、上升音、钟花饰）在每个"You do! You do!"之下 -4 dB；
  整个乐队在唱出的"Keep it."（75.0 秒）那一拍 -4 dB，它的拍手和边击也打得更轻（0.45 / 0.35）；
  重启和弦随副歌 3 里的铺底一起泵动（正是那个未泵动的层让副歌 3 的泵动变浅）。
- **段落能量**：乐队（鼓、贝斯、键盘、其他）按段落增益，使得*整个混音*相对副歌 1
  测到它的目标响度，与求解前测到的一样（intro -2，主歌 -3.2，
  前副歌 -2 带内部 3 dB 的积累，副歌 1 和 2 +1，后副歌 -0.7，过桥 -2，间奏 -3，
  最后副歌 +1.6，尾声 -1.5 LU；增益钳制在 -9..+3 dB），人声不动。求解出的增益在
  `song-qa.json` -> `mix.section_energy_db`。
- **FADE**：鼓/贝斯/键盘/其他降 6 dB，并在 1.5 拍里被 60% 重量化到 7 bit、带 TPDF 抖动。
- **静音窗口**（`parts.silence`，131.25-132.0 秒）：每条分轨在 8 ms 内被淡成
  131.25 秒处的精确零；领唱的"the"（渲染在自己的轨道上，自己的链路，无送出）和作者的按键
  （131.625 秒，比第一轮轻 5 dB，好让它坐在"the"之下：一次干的点击）被加回来；母带之后
  这个窗口被重新遮罩，好让除了这两个声音以外它是逐比特精确的数字静音（测得）。

## 8. 已知限制

- Whisper 是 PSOLA 演唱语音在 D5-E5 上的严苛裁判，在完整混音的 2 秒窗口里它不稳定：一条
  总线 0.5 dB 的变化就会让单行在正确与错误之间翻转，所以评判一次混音改动要看整行
  集合，而不是单独一行。它不转写的行列在上文。那些笑料本意就是毁伤词（FADE、冻结的"voice"），
  而喊出的团伙和 la-la 靠曲线而非文本评判（SONG.md 第 5 节）。
- Piper 声音以 22.05 kHz 采样；人声 11 kHz 以上的空气感由激励器合成。
- Piper 自己的随机采样器被关掉（零噪声）以保证确定性；加倍和堆叠采样之间的多样性
  来自不同的声音、Piper 速度、共振峰移位、失谐和时间。
