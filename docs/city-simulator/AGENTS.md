# AGENTS.md — Bonsai City (original city simulator)

Scope: the original, MIT-clean city-building simulator inside AI System 6,
officially named **Bonsai City / 盆景城市**. This file is the scoped rule set for
any agent touching that path. The GPL game engines (Micropolis, OpenTTD,
DOOM) are separate products; rules here do not govern their vendor code.

## Hard rules

1. **No GPL or original-game code in the Bonsai path.** Never copy, port, or
   approximate OpenSC2K (GPL), micropolisJS (GPL), OpenTTD (GPL), or any
   Maxis/EA code, art, sound, copy, data, or brand assets. SimCity 2000
   *game behavior* (rules, numbers the player sees, file format) may be
   reimplemented clean-room from public facts and from observation of a
   legally-owned copy; its *expression* (code, assets, text) may not enter.
   Visual fidelity (owner decision, 2026-08-24): the Macintosh releases are
   the reference — observed color values and layout/proportion measurements
   are facts and may guide our original artwork; sprites, tiles, traced
   outlines, and screenshots-as-assets remain expression and stay out.
2. **The simulation core stays headless.** No DOM, canvas, window, IndexedDB,
   wall clock, timers, or `Math.random()`. The shell owns seed generation and
   pacing; the core owns rules, ticks, and deterministic state.
3. **`.sc2` compatibility is clean-room and fixture-disciplined.** The codec
   is written from SC2k-docs facts in independent wording with attribution;
   OpenSC2K parser code is never consulted for implementation. Test fixtures
   are synthetic (generated by project code); EA-origin city files are never
   committed, bundled, or uploaded — user-supplied cities load at runtime
   only (the DOOM local-IWAD pattern).
4. **Phase boundaries are contract-gated.** The phase 9 contract authorizes
   the existing window, lazy manifests, dedicated store, original runtime
   atlases, the lazy three.js voxel renderer backend (Canvas 2D retained as
   the WebGL-unavailable fallback; both read `buildRenderSnapshot` only),
   and the clean-room `.sc2` codec. It still does not authorize a new npm
   dependency, an `indexedDbVersion` bump, or another application framework;
   changing any of those requires an explicit contract decision first.
5. **Every durable decision lands in the hub.** Update
   `foundation-contract.json` and the docs in the same change that changes the
   decision; `tests/features/city-simulator-foundation.test.mjs` must stay
   green. Do not keep private copies of names, versions, or rules in one file.

`verify:ship`) in an environment with the canonical fidelity cache.
