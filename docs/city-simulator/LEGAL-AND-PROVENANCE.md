# Bonsai City — License and Provenance

<!-- doc-claims: verified | audited: 2026-09-18 -->

This file is the construction rule for what may enter the original Bonsai City
path. It is a conservative engineering boundary, not legal advice.

## The one-line rule

The Bonsai City path stays MIT-clean: original code and original assets only,
written from public, non-copyrightable ideas and first principles.

## Boundary table

| Material | Allowed | Forbidden |
| --- | --- | --- |
| OpenSC2K (GPL v3) | Read, record high-level facts, cite a pinned commit | Copy, port, approximate-rewrite, extract tests/enums/tables/flows/structure |
| micropolisJS (GPL v3 + terms) | Keep as a separate lazy vendor game payload; read its save *data shape* (JSON field names, tile numbers) as format facts so Bonsai can summon a city and send one back | Any contribution to the Bonsai path — no engine code, tables, or algorithms; trademark "MICROPOLIS" is licensed only to that project |
| OpenTTD (GPL v2), DOOM | Separate game payloads | Any contribution to the Bonsai path |
| Original MIT/ISC upstreams | Future use only after separate review from the original upstream, with license retained | Back-port from GPL adaptations of those upstreams |
| SC2k-docs (CC BY-SA 4.0) | Cite with attribution; record independently worded protocol facts | Verbatim text, tables, diagrams, or extracted data |
| Maxis / EA / SimCity 2000 | Reimplement game behavior clean-room (rules, player-visible numbers, file format) from public facts and observation; study the Macintosh releases from a legally-owned copy and reuse *observed facts* — color values, layout proportions, structural composition — in our own original artwork (owner decision, 2026-08-24; the same line extends to SimCity 3000, SimCity 4 and SimCity (2013) since 2026-09-28) | Code, sprites, tiles, sounds, copy, cities, scenarios, screenshots-as-assets, brand assets, converted data, traced artwork, automated extraction of art assets |
| `.SC2` fixtures | Synthetic files generated by project code (exporter / fixture builder), with provenance | Committing, shipping, or referencing EA-origin city files (NEWCITY, TESTCITY, etc.) |
| User-supplied `.sc2`/`.scn` files (the owner's or a player's own copies) | Runtime import through the local file picker, processed entirely in the browser (the DOOM local-IWAD pattern) | Committing, bundling, uploading, or redistributing them |
| OpenStreetMap data (ODbL 1.0) | Fetched at runtime for a player's own city through the server relay (`/api/bonsai/osm`), mapped by `bonsai-osm-import.js`, credited "© OpenStreetMap contributors" on the map, in Map Setup, in the save's `provenance` record and in every export notice | Committing, bundling or shipping OSM extracts; tests that reach the network; dropping the credit from a city built on OSM ground |
| Terrain Tiles (AWS Open Data, Mapzen terrarium) | Fetched at runtime and sampled to one height per tile, credited with its sources (USGS, NOAA and the regional agencies tilezen/joerd lists) | Committing or shipping tiles |
| AI System 6 MIT code | Everything in the original path | Absorbing GPL code to keep an MIT file |
| Original art/sound/copy/data | Create and register in a provenance manifest (author, date, tool, license, source); matching color values observed from the reference is allowed | Tracing original outlines, tiles, sounds, or copy — shapes and pixels stay ours alone |

## Decisions

- **2026-09-29 — Real-place import from OpenStreetMap (owner directive,
  2026-09-28).** The owner chose a base map with optional import of existing
  buildings (imported buildings arrive as grown lots), 16 m a tile, and real
  heights from AWS Terrain Tiles. Licensing review: OSM data is under the
  Open Database License 1.0. The Bonsai code that maps it stays MIT; the
  *data* is never committed or shipped — the server relay fetches it for the
  player who asked, and the importer's contract builds synthetic fixtures at
  test time. A city built on OSM ground is a derivative database: it carries
  `provenance` { source, attribution "© OpenStreetMap contributors", license
  "ODbL-1.0", elevation credit, place, bbox, retrieval time } through every
  save; the map shows the credit while that city is on screen; the JSON,
  `.sc2` and `.cty` exports tell the player the credit travels with the file,
  and a city sent to Micropolis carries it in its provenance stamp. A player
  who shares such a city publicly shares OSM-derived data under ODbL. Terrain
  Tiles require crediting their sources, which the setup and the provenance
  record do. The relay names the application in its User-Agent, caches
  answers, runs one Overpass query at a time, keeps a daily ceiling on
  uncached queries, and obeys Nominatim's one-request-a-second rule; on the
  public deployment it sits behind the Turnstile session and the reader
  pool, because the public Overpass instances ask not to be the backend of a
  public site at scale (an operator can point `BONSAI_OVERPASS_URLS` at their
  own instance).

- **2026-09-11 — Original generated material remaster authorized (owner directive).**
  Original artwork made with the subscription's built-in `image_gen.imagegen`
  tool is permitted as checked-in authoring input. The tool does not expose an
  exact model version; GPT Image 2.5 was requested but is not claimed as verified.
  Keep the original image, prompt, tool identification, unknown model status and
  SHA-256 with the provenance record. Offline deterministic builds combine that
  artwork with project-owned semantic recipes and shared geometry to produce
  four-direction sprites, 48 colour texture tiles and independent material masks.
  Ordinary builds have no image-generation network dependency. This supplements
  the earlier hand-authored workflow; all existing prohibitions on copied,
  traced or extracted game expression remain in force.

- **2026-09-03 — Two-way save interop authorized (owner directive).** The
  owner chose bidirectional lossy conversion between Bonsai City and the
  separate Micropolis game, with a "what was lost" report on every
  conversion. Licensing review for this decision: a save is a data format,
  not code. `bonsai-micropolis-codec.js` (inbound) and
  `bonsai-micropolis-export.js` (outbound) are MIT modules that read and
  write plain JSON numbers in the shape the Micropolis shell stores; the
  classic tile numbers and flag bits they use are public format facts,
  confirmed by observing the vendored engine's own output in tests, and no
  engine code, lookup table, or algorithm is copied or ported. The outbound
  module writes one record into the GPL game's `cities` IndexedDB store with
  `provenance: { from: "bonsai-city", cityId, exportedAt }`; no GPL text
  enters the MIT path, and the foundation scans stay the gate. The `.cty`
  container (`micropolis-cty-codec.js`) is written clean-room from the
  public classic city-file layout; no EA-origin `.cty` file is ever
  committed, bundled, or referenced — user files load at runtime only.

- **2026-09-28 — SimCity 3000, SimCity 4 and SimCity (2013) added as visual
  references (owner directive).** The owner widened the 2026-08-24 reference
  from the Macintosh SimCity 2000 releases to three later city builders, for
  a new miniature direction: individually designed voxel buildings finished
  with tilt-shift depth of field, and a second, hybrid tier (live terrain,
  baked buildings). The line does not move: observed color values and
  layout / proportion / composition measurements are facts; sprites, models,
  textures, traced outlines, screenshots shipped as assets, sounds, copy,
  brand assets and converted data from any of these games stay prohibited,
  and every piece remains our own original work registered in a provenance
  manifest. Reading an installed copy at runtime is still excluded.

- **2026-08-24 — Visual fidelity reference authorized (owner directive).**
  The owner set the Macintosh SimCity 2000 releases as the visual fidelity
  reference for Bonsai City's own artwork and moved the palette line:
  color values observed or sampled from a legally-owned copy, and layout /
  proportion / composition measurements, are *facts* and may guide or enter
  our original art. Licensing review for this decision: individual color
  values and measurements carry no copyrightable expression; what does —
  sprites, tiles, pixel art, traced outlines, screenshots shipped as
  assets, sounds, copy, brand assets, converted data — remains fully
  prohibited, and every finished piece stays our own original work (hand-authored at that stage)
  registered in the provenance manifest. Reading a player's installed copy
  at runtime (the DOOM local-IWAD pattern applied to art) is *not* part of
  this decision and would need its own amendment.

- **2026-08-23 — SC2000 parity program authorized (owner directive).** The
  owner ordered SimCity 2000 gameplay parity, bidirectional `.sc2` save
  compatibility, and a three.js voxel renderer backend. Licensing review for
  this decision: game mechanics are not copyrightable and may be
  reimplemented; the `.sc2` container format is implemented clean-room from
  SC2k-docs facts (CC BY-SA 4.0 — facts recorded in independent wording with
  attribution; the license covers the document's expression, which is not
  copied); OpenSC2K (GPL v3) stays research-only and its parser code is not
  consulted for implementation; EA expression (code, art, sound, text, city
  files) remains fully prohibited. `three` was already a project
  devDependency (CMF Studio); bundling a second lazy ESM subset adds no new
  dependency.

## Practical guards

- The Bonsai simulation core is headless and self-contained; it must never
  `import` or concatenate GPL vendor engines.
- If a requirement looks like it needs OpenSC2K or an original-game resource,
  re-derive it from first principles instead of reaching for a forbidden
  source.
- Public format facts may be recorded in independently worded notes
  (see [OPENSC2K-RESEARCH.md](OPENSC2K-RESEARCH.md)); verbatim extraction is
  not.
- The `.sc2` codec (`bonsai-sc2-codec.js`) is written from SC2k-docs facts
  only, with attribution recorded in OPENSC2K-RESEARCH.md. Its tests build
  every fixture at test time; no city file binary is ever checked in.
- Any new runtime asset needs a provenance entry before merge.
- OpenStreetMap and terrain data enter only at runtime, through
  `apps/server/server/bonsai-osm.js`; `tests/features/bonsai-osm-import.test.mjs`
  keeps the importer offline and deterministic and checks the credit travels.
- The four-direction Canvas sprite atlases are registered at
  `assets/bonsai/provenance.json` (author, date, tool, MIT license,
  `source: original`); `tooling/build-bonsai-atlas.mjs` regenerates them from
  project-owned JSON descriptions, shared geometry and registered original
  generated material artwork. Rendered atlas PNGs are build outputs; the saved
  generated material plate is an authoring source with its own provenance.
  Neither generator reads or extracts art from an external game.

## Naming

- "Bonsai City / 盆景城市" is the approved product name.
- Do not use "SimCity", "OpenSC2K", "Micropolis", or Maxis/EA names for the
  original product. "MICROPOLIS" is a registered trademark of Micropolis GmbH
  and belongs to the separate GPL game line only.

## Enforcement

`tests/features/city-simulator-foundation.test.mjs` scans the original path
for `Math.random`, references to the separate GPL game engines, EA-origin
`.SC2` fixtures, and unapproved registration or schema changes. The scoped
AGENTS file makes these rules the standing instruction for any agent.
