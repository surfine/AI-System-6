# 盆景城市 —— SimCity 2000 存档兼容

状态：**双向——导入（M2）与导出（M7）均已上线**；最后的认证步骤是下文
的所有者手工验证。由 phase 9 契约授权；许可规则见
[LEGAL-AND-PROVENANCE.md](LEGAL-AND-PROVENANCE.zh-CN.md)。

**导出**：每座已存城市在 JSON 导出旁提供「导出 .sc2」。原生城市合成全部
段（64/96 地图居中嵌入 128 见方的咸水海域）；导入城市对模型未拥有的
一切（标签、标牌、活动物、未建模的 MISC 字段）逐字节重发其保留的
sidecar，只覆写建模字段。RLE 编码器是规范化的，因此我们自己的输出跨
往返逐字节稳定——由性质测试套件证明。

## 现在能做什么

Open Cities → 导入 现在同时接受 `.sc2` 城市文件与原生
`.bonsai-city.json`。文件按其 `FORM` 容器魔数识别，完全在浏览器内解析
（优先 worker，有界回退到主线程），并保存为一条新的原生城市记录。任何
内容都不会上传，源文件也不会被修改。

导入器逐格映射：海拔与水位（ALTM），含瀑布、溪流与海湾的水体分类
（XTER），盐度与占地旋转（XBIT），含军事/机场/海港的分区（XZON），道路、
铁路、电线、树木与公园（XBLD 区段），水管、地铁与交叉（XUND），以及带
尺寸等级与施工/废弃状态的 R/C/I 建筑。城市标量来自 MISC：资金、建城
年份、城市年龄（转为 tick）、住宅税率与五项服务拨款水平。有原生等价物
的电厂与服务建筑成为可工作的设施（电厂按输出类别映射）。

每个解压后的段都逐字保留在存档的 `sc2Sidecar` 里，导入尚未模拟的内容
不会丢失；导出（M7）将从这些字节出发。

## M2 已知近似

- SC2K 电厂为 4×4。原生新建的煤电厂现在占满 4×4（存档规则 3.1）；导入器
  仍把其他电厂种类和任何导入的煤电厂开在较小的锚点占地上，这类记录在地图上
  保持该尺寸（查询气球标注「旧版 2×2 电厂」）。把导入器的煤电厂占地映射到
  完整 4×4 属于编解码器工作。`catalogId` 在每一格保留真实建筑 id。
- 高速公路与匝道已是工作图层（M3b-2b）：导入的高速 id（含立交与加固
  桥）落在 `highway` 图层，立交同时保留其下穿的道路/铁路/电线，匝道 id
  落在 `onramp`。原生导出写两种直行、四种弯道与四向路口；丁字路口落到
  四向件，匝道以未旋转族为 canonical。导入的匝道格不再兼算道路格。
  道路隧道仍按道路格处理。
- 铁路车站尚未映射为可工作车站（M3）。
- 标签与标牌仍暂存于 sidecar，待其里程碑。活动物（M6-3）：XTHG 的民用
  种类——飞机、直升机、货轮、帆船——导入即成为活的活动物，原生城市
  导出会写出它们；导入城市的 XTHG 经 sidecar 逐字重发，部署、怪兽与头
  记录绝不丢失，代价是模拟中的移动不会进入导入城市的再导出。
- 64×64/32×32 派生网格由我们的模拟重算：`sc2DerivedGrids(state)` 是纯读取，
  无论地图尺寸，都按格均值把交通降采样到 64×64，把污染、地价、犯罪、警力、
  消防降采样到 32×32。导出会把 XTRF/XPLT/XVAL/XCRM（四分之一网格）与
  XPLC/XFIR/XPOP（十六分之一网格）以及 XROG/XGRP 从活模型写入；导入把原
  网格段原样保留在 sidecar，显示读模拟重算网格，因此导入城市的叠加层始终
  匹配其运行状态而非陈旧快照。

## 所有者手工验证（使用合法拥有的 SC2K 副本）

任何 EA 原版城市文件都绝不提交、打包或上传。以下步骤全部在所有者
本机运行：

1. 在你自己的 SimCity 2000 副本里保存一座城市。
2. Bonsai City → Open Cities → 导入 → 选择 `.sc2` 文件。
3. 与原版游戏各窗口对照：地图布局与海岸线、资金、日期（年份）、税率、
   拨款水平、分区与建筑密度、道路/铁路/电力/水管/地铁网络。
4. 以正常速度运行一个游戏年；记录任何不该衰退却衰退的内容（按系统
   逐条记录）。
5. M7 之后：导出回 `.sc2`，在 SimCity 2000 里重新载入，确认游戏接受
   该文件且城市可以继续游玩。

发现写入实施状态文件；差异馈入对等调校里程碑。

## Fixture 政策

编解码器测试在运行时合成生成全部 `.sc2` fixture
（`tests/features/bonsai-sc2.test.mjs`）。RLE 边界情形使用手写字节数组。
仓库中不存在任何城市文件二进制。
