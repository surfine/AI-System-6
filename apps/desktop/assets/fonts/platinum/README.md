# Platinum font fallback

`Asap-Variable.woff2` is the legal, cross-platform fallback for the historical
Charcoal target. Installed `Charcoal` and `Charcoal CY` faces still take
priority; macOS `Geneva` remains the last era-adjacent local fallback.

- Upstream: <https://github.com/Omnibus-Type/Asap>
- Commit: `2de32f20d7a0d48d4084adcf4bd6ac8115cf2f1a`
- Source file: `fonts/webfonts/Asap[wdth,wght].woff2`
- SHA-256: `3f230328a40ee9a05fe099dfb6b403a4c569aaea6690e5d483d5715ed817498f`
- License: SIL Open Font License 1.1; see `OFL.txt`

The fallback is not represented as an original Apple font. Platinum uses its
width axis at 113 and a 650 regular UI weight to match the measured Charcoal
sample's x-height, advance width, and compact system-control rhythm.
