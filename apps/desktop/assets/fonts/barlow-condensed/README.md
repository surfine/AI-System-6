# Endfield Terminal label face

`BarlowCondensed-SemiBold-latin.woff2` sets the small English terminal tags
(ARCHIVE, EVIDENCE, VERDICT…) and the archive coverage figures inside the
Endfield Terminal, and only in the colour appearances. It is declared in
`styles/90-endfield-terminal.css`, which is a lazy style bundle, so the face
never costs boot bytes. Chinese text keeps the appearance's own faces.
